プライバシーポリシー — Hamoly

制定日: 2026年8月30日

基本方針

「Hamoly」（以下「本アプリ」）は、お客様の個人情報を収集・送信しません。

データの保存場所

  • 持ち歌リスト、メモ、録音、採点記録、写真等のデータは、お客様の端末内にのみ保存されます
  • 録音データは端末の外に出す機能自体がありません（共有・アップロード不可の設計です）
  • 開発者を含む第三者がお客様のデータにアクセスすることはできません

通信について

本アプリが通信を行うのは、曲を検索するとき（Apple の iTunes Search API へ検索語を送信し、曲名・アーティスト名・ジャケット画像を取得）のみです。お客様の個人情報や端末情報は送信しません。

マイク・カメラの利用

  • マイク: 歌の練習メモの録音、および音域測定に使用します。音域測定の音声はその場で解析されるのみで保存されません
  • カメラ・写真: カラオケ採点画面の読み取りに使用します。文字認識は端末内で処理され、画像が外部に送信されることはありません

持ち歌ファイルの共有

持ち歌リストのファイル書き出しはお客様の明示的な操作でのみ行われ、共有相手の選択もお客様ご自身が行います。
